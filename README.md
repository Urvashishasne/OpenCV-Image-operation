OpenCV Image Operations 🚀          
              
📌 About This Repository      
This repository contains various image operations and processing techniques using OpenCV. It serves as a collection of fundamental to advanced image processing scripts, helping learners understand OpenCV functionalities.    
          
🛠 Features      
✅ Basic Image Operations (Read, Write, Resize)      
✅ Image Processing (Grayscale, Edge Detection, Blurring)    
✅ Advanced Techniques (Face Detection, Object Detection)      
✅ Well-Structured Code with Examples      

📌 **Want to learn about OpenCV before diving in?**  
👉 Read the full introduction here: [OpenCV Introduction](OpenCV_Introduction.md)
