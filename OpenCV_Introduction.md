## 📸 Understanding Images in OpenCV
Before working with OpenCV, it's important to understand **what an image is** and the different formats it supports.

### 🖼️ What is an Image?
An image is a **collection of pixels** arranged in a **2D matrix**, where each pixel has intensity values that define its brightness and color.

### 📷 Types of Images in OpenCV
1️⃣ **Grayscale Images** – Single channel (0-255 pixel values)  
2️⃣ **RGB Images** – 3-channel color images (Red, Green, Blue)  
3️⃣ **Binary Images** – Only black and white (0 or 255)  
4️⃣ **Indexed Images** – Uses a color map for pixel representation

## 🚀 Getting Started with OpenCV
### 🔹 Installation
To install OpenCV in Python, run:
```bash
pip install opencv-python numpy matplotlib
```

### 🔹 Read and Display an Image
```python
import cv2

# Load an image
img = cv2.imread('image.jpg')
cv2.imshow('Image', img)
cv2.waitKey(0)
cv2.destroyAllWindows()
```
